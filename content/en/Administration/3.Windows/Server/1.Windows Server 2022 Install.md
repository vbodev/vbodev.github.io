## Installing Windows Server 2022 on VirtualBox

### Step 0: Preparation
1. Install **Oracle VirtualBox**.
2. Download ISO image: `Windows Server 2022 Evaluation ISO download`.
### Step 1: Creating a virtual machine
1. Launch VirtualBox -> Click the **"New"** button.
2. **Name:** `WinServer2022`. **Folder:** where there's space (~30 GB required). **ISO Image:** select the downloaded file.
3. **Important:** Check _"Skip Unattended Installation"_ to control the process.
4. **Hardware:**
    - RAM: Minimum **4096 MB** (4 GB).
    - CPU: **2 vCPU**.
5. **Hard Disk:** Create a new virtual disk, **50 GB** is enough.
### Step 2: Installing Windows (The Most Important Moment!)
1. Start the virtual machine. ISO loading begins.
2. Select language (English or German, better English for learning, but in Austria servers are often German).
3. Click "Install Now".
4. 🚩 **CRITICAL MOMENT:** You'll be offered a version choice.
    - Select: **Windows Server 2022 Standard Evaluation (Desktop Experience)**.
    - _Why:_ If you select just "Standard Evaluation" (without Desktop Experience), the **Core** version will be installed — that's just a black console without a mouse and windows. For a beginner, that's a shock. You need the graphical interface (GUI).
5. Select "Custom: Install Windows only (advanced)". Select the disk and click Next.
### Step 3: Initial configuration
1. After restarting, it will ask to set a password for the `Administrator` user. Create a strong one (e.g.: `Start2026!`).
2. You'll see the desktop. **Server Manager** (Server Administration) will start immediately — this is your main panel.
### Step 4: Installing Guest Additions (for normal screen size)
1. In the VirtualBox window menu at top: **Devices -> Insert Guest Additions CD image**.
2. Inside Windows Server, open "This PC", open the CD drive and run the installer (`VBoxWindowsAdditions.exe`).
3. Install, restart. Now the screen can be resized and the clipboard will work.
