Return to the Zabbix Server web interface:
1. In the left menu: **Data collection** -> **Hosts**.
2. Top right button: **Create host**.
3. Fill in the card:
    - **Host name:** `Zabbix Agent Name` (Exactly as you entered it during agent installation!).
    - **Templates:** Start typing `Windows` and select **Windows by Zabbix agent** (the standard template).
    - **Host groups:** Select e.g. `Discovered hosts` or create a new one `Lab Servers`.
    - **Interfaces:** Click **Add** -> **Agent**.
        - **IP address:** Enter the IP of your Zabbix Agent.
        - **DNS name:** Leave empty.
        - **Port:** `10050` (don't change).
4. Click the blue **Add** button.

**View errors in the server log:**
```bash
tail -f /var/log/zabbix/zabbix_server.log | grep "Error"
```
**Ports used:**
```
10050/10051
```
