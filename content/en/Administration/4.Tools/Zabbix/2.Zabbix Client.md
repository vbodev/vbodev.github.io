Installation:
1. Download Zabbix Agent 2 (MSI):
	[Zabbix agents](https://www.zabbix.com/download_agents)
2. Start the installation.
3. The most important part (Configuration):
    - **Host name:** client name.
    - **Zabbix server IP:** Enter your Zabbix server's IP.
    - **Server or Proxy for active checks:** Also enter your Zabbix server's IP.
4. Click Next -> Install.

Config file `C:\Program Files\Zabbix Agent\zabbix_agentd.conf`:
	Server=server ip
	ServerActive=server ip
	Hostname=Agent Name
