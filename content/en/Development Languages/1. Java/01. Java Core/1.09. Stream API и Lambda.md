## Filtering
```java
List<String> names = List.of("Alice", "Bob", "Carl", "Anna");
List<String> filtered = names.stream()
    .filter(n -> n.startsWith("A"))
    .toList();
System.out.println(filtered); // [Alice, Anna]
```

## Map (Transformation)
```java
List<String> upper = names.stream()
    .map(String::toUpperCase)
    .toList();
System.out.println(upper); // [ALICE, BOB, CARL, ANNA]
```

## Collectors.groupingBy
```java
Map<Integer, List<String>> grouped = names.stream()
    .collect(Collectors.groupingBy(String::length));
System.out.println(grouped);
// {3=[Bob], 4=[Anna], 5=[Alice, Carl]}
```

## Explanation:

This section demonstrates common stream operations in Java.

*   **Filtering:**  Selects elements from a stream based on a given condition. In this case, it filters the `names` list to include only strings that start with the letter "A".
*   **Mapping:** Transforms each element of a stream by applying a function. Here, it converts each string to uppercase.
*   **`Collectors.groupingBy`:** Groups elements of a stream based on a provided function that maps each element to a key.  The result is a map where keys are the grouping criteria (string length) and values are lists of elements that share that key.

These operations are fundamental for data manipulation and analysis using Java streams. They allow for concise and efficient processing of collections of data.
