## 🧱Порождающие (Creational)

#### 1) Singleton
[[17d3375cbba708b2d8759d75db7c913e_MD5.jpeg|Open: Pasted image 20251006002210.png]]
![[17d3375cbba708b2d8759d75db7c913e_MD5.jpeg]]
**Назначение:** гарантирует, что в системе существует **только один экземпляр класса**, и предоставляет к нему глобальную точку доступа.  
**Где используется:**  
– классы для работы с конфигурацией;  
– классы логирования;  
– пул соединений с БД.

**Пример:**
```java
public class Logger {
    private static Logger instance;

    private Logger() {} // приватный конструктор

    public static synchronized Logger getInstance() {
        if (instance == null) {
            instance = new Logger();
        }
        return instance;
    }

    public void log(String msg) {
        System.out.println(msg);
    }
}
```
**Использование:**
```java
Logger.getInstance().log("Started app...");
```
