## 🧠 1. **OpenAI Whisper (оригинал)**

**Язык:** Python  
**Разработчик:** OpenAI  
**Архитектура:** Transformer-based model (tiny → large-v3)
**Ссылка:** [openai/whisper](https://github.com/openai/whisper)
### 💡 Особенности

- Это **эталонная реализация**, на которой основаны все остальные версии.   
- Очень **точная**, особенно на моделях `medium` и `large`.
- Поддерживает **более 100 языков**, включая украинский и русский.
- Работает через `ffmpeg` и требует предварительной записи файла (не стримит).
- **Нет встроенной разбивки по спикерам** (speaker diarization нужно добавлять отдельно, например через `pyannote.audio`).
### ⚙️ Производительность

- **Медленный inference**: даже на GPU не идеально подходит для real-time.
- Использует **FP32 (float32)**, можно ускорить FP16 на GPU.
- На CPU работает, но медленно.

## ⚡ 2. **whisper.cpp**

**Язык:** C++ (с Python bindings)  
**Разработчик:** Georgi Gerganov  
**Цель:** Быстрое и лёгкое исполнение Whisper без Python-зависимостей
**Ссылка:** [whisper.cpp](https://github.com/ggml-org/whisper.cpp)
### 💡 Особенности

- Переписан полностью на **C++** с использованием **quantization (int8/int4)** — это радикально ускоряет обработку.
- **Можно запускать в реальном времени** даже на CPU (включая Raspberry Pi и ESP32-подобные устройства).
- Имеет **streaming API** — можно подавать аудио по кускам и получать частичные результаты.
- Поддержка **GPU (CUDA, Metal, OpenCL)** добавлена, но не всегда стабильна.
- **Нет встроенной спикер-диаризации**, только текст.
### ⚙️ Производительность

- **Очень быстро**, особенно в режиме `int8`.
- Идеален для **реального времени**, особенно если спикеры не важны.
- Можно встраивать прямо в C++-приложения, без Python.

## 🚀 3. **Faster Whisper**

**Язык:** Python  
**Разработчик:** Guillaume Klein (основан на Whisper + CTranslate2)  
**Архитектура:** CTranslate2 — высокопроизводительный inference engine на C++
**Ссылка:** [Faster-Whisper](https://github.com/SYSTRAN/faster-whisper)
### 💡 Особенности

- Полная совместимость с OpenAI Whisper, но:
    - Использует **CTranslate2**, а значит в 2–5 раз быстрее оригинала.
    - Поддерживает **FP16 и INT8**, отлично работает на GPU и CPU.
- Поддержка **streaming inference (реальное время)**.
- Можно использовать **batch processing** (ускоряет при обработке длинных записей).
- **Поддерживает интеграцию с diarization** (через `pyannote.audio`).
### ⚙️ Производительность

- **Быстрее оригинала в 2–4 раза** на CPU и GPU.
- Хорошо подходит для **реального времени**, особенно с GPU.
- Меньше потребление памяти.
- Прост в интеграции с Python-системами (Flask, FastAPI и т.д.).

## 🔊 4. **WhisperX**

**Язык:** Python  
**Разработчик:** Max Bain (University of Oxford)  
**Цель:** Расширение Whisper для точной **диаризации и выравнивания (alignment)**
**Ссылка:** [WhisperX](https://github.com/m-bain/whisperX)
### 💡 Особенности

- Использует **Faster Whisper** для транскрипции.
- Добавляет:
    - **Speaker diarization** (через `pyannote.audio`)
    - **Phoneme-level alignment** (точная синхронизация слов с временными метками)
- Может использовать GPU для всего пайплайна.
- Поддерживает **многоязычные модели** и автоматически определяет язык.
- Можно обрабатывать **длинные записи** и получать структуру «кто и когда говорил».
### ⚙️ Производительность

- Немного медленнее Faster Whisper (из-за дополнительных этапов), но **гораздо функциональнее**.
- Не идеально для real-time (обычно работает на chunks 15–30 сек).
- Однако можно сделать “почти real-time”, если обрабатывать короткие буферы аудио.
