## 1. Подключение БД в Spring Boot

📄 application.yml
```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/demo
    username: demo
    password: secret
    driver-class-name: org.postgresql.Driver
  jpa:
    hibernate:
      ddl-auto: update   # create, update, validate, none
    show-sql: true       # показывать SQL в консоли
    properties:
      hibernate.format_sql: true
```
## 2. JPA + Hibernate

Spring Data JPA = обёртка над Hibernate.  
Позволяет работать с БД как с объектами.

**Entity (таблица)**
```java
import jakarta.persistence.*;
@Entity
@Table(name = "users")
public class User {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    @Column(nullable = false)
    private String name;
    private String email;
    // геттеры/сеттеры
}
```

**Репозиторий (DAO слой)**
```java
import org.springframework.data.jpa.repository.JpaRepository;
public interface UserRepository extends JpaRepository<User, Long> {
    // автоматические методы по имени
    List<User> findByName(String name);
    List<User> findByEmailContaining(String part);
}
```
Spring сам создаст реализацию на основе имени метода.

**Сервисный слой**
```java
@Service
@RequiredArgsConstructor
public class UserService {
    private final UserRepository repo;

    public User createUser(User u) {
        return repo.save(u);
    }

    public List<User> allUsers() {
        return repo.findAll();
    }
}
```

**Контроллер**
```java
@RestController
@RequestMapping("/api/users")
@RequiredArgsConstructor
public class UserController {
    private final UserService service;

    @GetMapping
    public List<User> all() {
        return service.allUsers();
    }

    @PostMapping
    public User create(@RequestBody User user) {
        return service.createUser(user);
    }
}
```
## 3. JPQL & Native Queries

📌 Если не хватает магии findBy...
```java
public interface UserRepository extends JpaRepository<User, Long> {
    // JPQL (работает с Entity, а не с таблицами)
    @Query("SELECT u FROM User u WHERE u.name = :name")
    List<User> findByNameJPQL(@Param("name") String name);
    // Native SQL
    @Query(value = "SELECT * FROM users WHERE email LIKE %:email%", nativeQuery = true)
    List<User> findByEmailNative(@Param("email") String email);
}
```
## 4. DTO (Data Transfer Object)

Чтобы не возвращать Entity напрямую (опасно для API).
```java
public record UserDto(Long id, String name) {}
@Service
@RequiredArgsConstructor
class UserService {
    private final UserRepository repo;
    public List<UserDto> allUsers() {
        return repo.findAll().stream()
                   .map(u -> new UserDto(u.getId(), u.getName()))
                   .toList();
    }
}
```
## 5. Transaction Management

Spring Data JPA автоматически оборачивает методы save/delete в транзакции, но можно управлять вручную.
```java
@Service
public class BankService {
    @Transactional
    public void transfer(Account a1, Account a2, double sum) {
        a1.withdraw(sum);
        a2.deposit(sum);
        // если здесь исключение → весь метод откатится
    }
}
```
📌 По умолчанию: **rollback для RuntimeException**.
## 6. Отношения (Entity relationships)

**OneToOne**
```java
@Entity
class Profile {
    @Id @GeneratedValue Long id;
    String bio;
    @OneToOne
    User user;
}
```

**OneToMany / ManyToOne**
```java
@Entity
class User {
    @Id @GeneratedValue Long id;
    String name;
    @OneToMany(mappedBy = "user")
    List<Post> posts = new ArrayList<>();
}

@Entity
class Post {
    @Id @GeneratedValue Long id;
    String text;
    @ManyToOne
    User user;
}
```

**ManyToMany**
```java
@Entity
class Student {
    @Id @GeneratedValue Long id;
    String name;
    @ManyToMany
    @JoinTable(name = "student_course")
    Set<Course> courses;
}

@Entity
class Course {
    @Id @GeneratedValue Long id;
    String title;
    @ManyToMany(mappedBy = "courses")
    Set<Student> students;
}
```
## 7. Миграции БД (Flyway, Liquibase)

Лучше не полагаться на ddl-auto: update, а использовать миграции.

**Flyway**
📄 application.properties
```properties
spring.flyway.enabled=true
spring.flyway.locations=classpath:db/migration
```

📄 src/main/resources/db/migration/V1__init.sql
```sql
CREATE TABLE users (
  id BIGSERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(100)
);
```
При старте Spring Boot автоматически применит миграции.
## 8. Paging & Sorting

Spring Data JPA умеет автоматически пагинировать:
```java
@GetMapping
public Page<User> all(@RequestParam int page, @RequestParam int size) {
    return repo.findAll(PageRequest.of(page, size, Sort.by("name")));
}
```
📌 Ответ будет JSON с данными и метаинформацией (номер страницы, общее количество элементов и т. д.).
## 9. Best Practices

- ✅ **Не возвращай Entity в API** → используй DTO.  
- ✅ Всегда включай **миграции (****Flyway****/Liquibase****)**.  
- ✅ Для продакшн лучше ddl-auto=validate.  
- ✅ Транзакции — только в сервисном слое (@Transactional).  
- ✅ Используй **Pageable** для API → не нагружай БД.
- ✅ Разделяй **Repository** **→ Service** **→ Controller** (чистая архитектура).
