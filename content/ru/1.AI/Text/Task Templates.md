## 1. Пример. Написание статьи в блог 

```markdown
# Задача: Написание статьи в блог

## Тема
Как использовать ChatGPT для автоматизации задач разработчика

## Аудитория
Разработчики уровня Junior и Middle

## Объём
1000–1200 слов

## Структура
1. Введение
2. Примеры использования ChatGPT в повседневной разработке
3. Интеграция с VS Code / Postman / n8n
4. Потенциальные ошибки и ограничения
5. Заключение и советы

## Стиль
Полуформальный, с примерами кода, юмором и дружелюбным тоном

## Дополнительно
Упомяни возможности ChatGPT-4 и ChatGPT в десктопном приложении

```
## 2. Пример. Генерация кода на Python

```Markdown
# Задача: Генерация кода на Python для анализа данных

## Цель
Создать Python-скрипт, который читает CSV-файл, анализирует данные (среднее, медиана, стандартное отклонение) и строит график распределения.

## Входные данные
- CSV-файл с одной колонкой числовых значений.
- Название файла: `data.csv`
- Название колонки: `value`

## Выход
- Статистические метрики: среднее, медиана, стандартное отклонение
- Сохранённый график: `histogram.png`

## Требования
- Использовать библиотеки: pandas, matplotlib
- Код должен быть понятным и содержать комментарии

## Дополнительно
- Построй гистограмму с 20 бинами

```
## 3. Пример. Сгенерировать изображение

```markdown
# Задача: Сгенерировать изображение

## Тип изображения
Фантастический портрет девушки в стиле киберпанк

## Описание
- Молодая девушка с фиолетовыми волосами
- Неоновые огни, ночной город на фоне
- Кибер-очки и металлический воротник
- Эмоция: уверенность и независимость

## Размер
1024x1024 пикселей

## Стиль
Реалистичный + немного аниме

## Дополнительно
Фон должен быть немного размытым, основной акцент — на лице

```
## 4. Пример. ТЗ: Лендинг для ИТ-компании

```markdown
# ТЗ: Лендинг для ИТ-компании

## Название компании
NextGenSoft

## Цель
Привлечение клиентов на услуги по разработке ПО

## Блоки сайта
- Хедер с логотипом и навигацией
- Главный баннер (с логаном и кнопкой)
- Услуги (3 карточки)
- О компании (текст + фото)
- Форма обратной связи
- Футер с контактами

## Дизайн
- Цвета: синий, белый, серый
- Стиль: минимализм, шрифты без засечек

## Адаптивность
Да (мобильная и десктопная версии)

## Технологии
HTML, CSS (Tailwind или Bootstrap), JS (Vanilla)

## Срок
1 неделя
```

## 6. Шаблон Задачи на Python

````markdown
# 🐍 Задача на Python

## 📌 Название задачи
[НАПРИМЕР: Анализ CSV и визуализация данных]

## 🎯 Цель
[Опиши, зачем пишется скрипт и как будет использоваться результат]

## 📚 Контекст
- Язык: Python
- Версия: [3.10+]
- Используемые библиотеки: [pandas, matplotlib, requests, и т.п.]
- Где будет запускаться: [локально / сервер / Jupyter Notebook]

## 🛠 Что должно быть реализовано
1. [Прочитать CSV-файл]
2. [Построить график распределения]
3. [Сохранить результат в файл]

## ✅ Требования
- [Код с комментариями]
- [Обработка ошибок]
- [Формат ввода/вывода должен быть указан]

## 🔍 Пример входных данных
```csv
value
12
34
23
...
```

## 📤 Пример выходных данных
- Среднее: 23.1
- График: `histogram.png`

## 💬 Формат ответа от ChatGPT
- Полный код
- Объяснение логики
````

Пользователь: Vitaliy
