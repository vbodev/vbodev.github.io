## Установка Windows Server 2022 на VirtualBox

### Шаг 0: Подготовка
1. Установка **Oracle VirtualBox**.
2. Скачай ISO-образ: `Windows Server 2022 Evaluation ISO download`.
### Шаг 1: Создание виртуальной машины
1. Запусти VirtualBox -> Кнопка **"Создать" (New)**.
2. **Имя:** `WinServer2022`. **Папка:** где есть место (нужно ~30 ГБ). **Образ ISO:** выбери скачанный файл.
3. **Важно:** Поставь галочку _"Пропустить автоматическую установку"_ (Skip Unattended Installation), чтобы контролировать процесс.
4. **Hardware:**
    - RAM: Минимум **4096 MB** (4 ГБ).
    - CPU: **2 vCPU**.
5. **Hard Disk:** Создай новый виртуальный диск, **50 ГБ** достаточно.
### Шаг 2: Установка Windows (Самый важный момент!)
1. Запусти виртуалку. Начнется загрузка с ISO.
2. Выбери язык (English или German, лучше English для обучения, но в Австрии часто немецкие сервера).
3. Нажми "Install Now".
4. 🚩 **КРИТИЧЕСКИЙ МОМЕНТ:** Тебе предложат выбор версии.
    - Выбери: **Windows Server 2022 Standard Evaluation (Desktop Experience)**.
    - _Почему:_ Если выберешь просто "Standard Evaluation" (без слов Desktop Experience), установится версия **Core** — это просто черная консоль без мышки и окон. Для новичка это шок. Тебе нужен графический интерфейс (GUI).
5. Выбери "Custom: Install Windows only (advanced)". Выбери диск и жми Next.
### Шаг 3: Первичная настройка
1. После перезагрузки он попросит задать пароль для пользователя `Administrator`. Придумай сложный (например: `Start2026!`).
2. Ты увидишь рабочий стол. Сразу запустится **Server Manager** (Диспетчер серверов) — это твоя главная панель.
### Шаг 4: Установка Guest Additions (чтобы экран был нормальным)
1. В меню окна VirtualBox сверху: **Устройства (Devices) -> Подключить образ диска Дополнений гостевой ОС (Insert Guest Additions CD image)**.
2. Внутри Windows Server зайди в "This PC", открой CD-диск и запусти установщик (`VBoxWindowsAdditions.exe`).
3. Установи, перезагрузись. Теперь экран можно растягивать, и буфер обмена будет работать.

## Контроллер Домена (Active Directory)

### Шаг 0: Сделай "Снимок" (Snapshot) — Правило №1
Ты админ. Админы параноики. Прежде чем что-то менять, мы сохраняемся.
1. В окне VirtualBox (сверху): **Machine (Машина) -> Take Snapshot (Сделать снимок)**.
2. Назови: `Clean Install`.
3. _Теперь, если ты что-то сломаешь, ты сможешь откатиться сюда за 2 секунды._
### Шаг 1: Правильное имя (Identity)
По умолчанию сервер называется `WIN-394857...`. Это непрофессионально.
1. В Windows Server нажми `Win + X` -> **System**.
2. Нажми **Rename this PC (Advanced)**.
3. Введи имя: `SRV-DC01` (Стандарт: SRV = Сервер, DC = Domain Controller, 01 = первый).
4. Нажми OK. **Перезагрузись.**
### Шаг 2: Статический IP (Static IP)
Сервер не может иметь "плавающий" IP-адрес. Клиенты (компьютеры сотрудников) должны знать точный адрес "Босса". _Как программист, представь, что ты хардкодишь адрес базы данных в конфиге._
1. В VirtualBox убедись, что в настройках сети стоит **"Сетевой мост" (Bridged Adapter)** — так сервер получит IP от твоего домашнего роутера и будет "как живой" в твоей домашней сети.
2. В Windows Server нажми `Win + R`, введи `ncpa.cpl` (это быстрая команда открыть сетевые адаптеры).
3. Правой кнопкой на адаптер -> **Properties**.
4. Выбери **IPv4** -> Properties.
5. Переключи на **"Use the following IP address"**.
    - _Чтобы узнать, какие цифры писать:_ На хост-машине (твоем обычном компе) открой командную строку, напиши `ipconfig`. Посмотри свой IP и Gateway (Шлюз).
    - _Пример:_ Если твой роутер `192.168.0.1`, то серверу дай:
        - **IP address:** `192.168.0.200` (выбери высокий номер, чтобы не совпал с телефоном).
        - **Subnet mask:** `255.255.255.0` (сама встанет).
        - **Default Gateway:** `192.168.0.1` (IP твоего роутера).
        - **DNS:** `127.0.0.1` (ОЧЕНЬ ВАЖНО! Сервер будет спрашивать сам себя, так как он сам станет DNS-сервером).
### Шаг 3: Установка роли AD DS (Инсталляция)
1. Открой **Server Manager** (он обычно открыт сам).
2. По центру нажми **"Add roles and features"**.
3. Жми Next, Next, Next (выбираем наш сервер `SRV-DC01`).
4. В списке ролей поставь галочку напротив: **Active Directory Domain Services**.
    - Он спросит "Добавить фичи?" — Жми **Add Features**.
5. Жми Next до конца и **Install**.
6. _Жди окончания полоски._
### Шаг 4: "Повышение" сервера (Configuration)
Установка роли — это просто копирование файлов. Теперь нужно активировать.
1. В Server Manager сверху справа появится **желтый треугольник** ⚠️ (флажок). Нажми на него.
2. Нажми ссылку: **"Promote this server to a domain controller"**.
3. Откроется мастер настройки. Это самый важный момент!
    - Выбери опцию: **Add a new forest** (Добавить новый лес). Мы создаем новую организацию с нуля.
    - **Root domain name:** Придумай название. Для локальных тестов используют `.local` или `.lan`.
        - Напиши: `vbo.local` (или любое другое).
4. Жми Next.
5. Придумай пароль для DSRM (режим восстановления). Введи тот же, что и у админа, чтобы не забыть.
6. Жми Next, Next, Next (на предупреждение про DNS не обращай внимания).
7. Он проверит "Prerequisites". Если все зеленые галочки — жми **Install**.
8. Сервер сам перезагрузится. **Внимание:** Первая загрузка будет долгой (минут 5-10), он создает базу данных.


## Учетные записи для сотрудников

Теперь, когда сервер перезагрузился, и ты вошел под `VBO\Administrator` (или твоим доменным именем), перед тобой уже не просто Windows, а **Контроллер Домена**.
Два способа: "классический" (мышкой) и "профессиональный" (скриптом).
### Способ 1: GUI (Active Directory Users and Computers)
Это классическая консоль ("оснастка"), которой админы пользуются с 2000 года.
1. В **Server Manager** справа сверху нажми меню **Tools** (Инструменты).   
2. Найди и открой **Active Directory Users and Computers** (ADUC).
3. Разверни свой домен (нажми на стрелочку слева от `corp.vitaliy.local`).

**Правило хорошего тона №1:** Никогда не создавай живых людей в стандартной папке "Users". Она для системных нужд. Мы создадим свою структуру — **OU** (Organizational Unit, Подразделение).

1. Нажми **ПРАВОЙ** кнопкой мыши на название твоего домена (`corp...`).
2. Выбери **New -> Organizational Unit**.
3. Назови её: `Eberstalzell-Office` (или просто `IT-Dept`).
    - _Зачем это нужно:_ В будущем ты сможешь применять Групповые Политики (GPO) только к этому отделу (например, установить им всем Chrome автоматически).
4. Нажми OK.

**Теперь создадим сотрудника:**
1. Правой кнопкой на новую папку `IT-Dept` -> **New -> User**.
2. **First name:** `Hans`
3. **Last name:** `Muster` (немецкий аналог Ивана Иванова).
4. **User logon name:** `h.muster` (это логин, который он будет вводить при входе).
5. Жми Next.
6. Придумай пароль.
    - _Важно:_ Убери галочку _"User must change password at next logon"_ (чтобы не мучиться сейчас с тестами).
    - Поставь _"Password never expires"_ (для тестовой среды это удобно).
7. Жми Next -> Finish.
Поздравляю, Ханс принят на работу!
### Способ 2: PowerShell (The Programmer's Way) 🚀
Как программист, ты понимаешь: если нужно создать 100 пользователей, мышка отвалится. Давай создадим второго юзера кодом.
1. Нажми **Пуск**, начни вводить `PowerShell`.
2. Нажми правой кнопкой на **Windows PowerShell** -> **Run as Administrator**.
3. Введи (или скопируй) следующий код. Обрати внимание, как это похоже на создание объекта в ООП:

```powershell
# 1. Задаем пароль в безопасную переменную (попросит ввести при запуске)
$Password = Read-Host -AsSecureString "Введите пароль для нового юзера"

# 2. Создаем юзера одной командой
New-ADUser `
    -Name "Anna Tech" `
    -GivenName "Anna" `
    -Surname "Tech" `
    -SamAccountName "a.tech" `
    -UserPrincipalName "a.tech@vbo.local" `
    -Path "OU=IT-Dept,DC=vbo,DC=local" `
    -AccountPassword $Password `
    -Enabled $true

# Обрати внимание на Path:
# DC=vbo,DC=local — это части твоего домена. Измени их под свой!
# Если твой домен vbo.local, то будет: DC=vbo,DC=local
```
### Способ 3: PowerShell (The Programmer's Way) 🚀

#### Шаг 1: Подготовь файл данных (CSV)
Создай в блокноте файл `users.csv` и сохрани его, например, в `C:\users.csv`. Формат такой (заголовки обязательны):
Фрагмент кода
```csv
FirstName,LastName,LogonName,Department
Ivan,Petrov,i.petrov,Sales
Elena,Sidorova,e.sidorova,HR
Hans,Muller,h.muller,IT-Dept
Oleg,Popov,o.popov,Sales
Maria,Ivanova,m.ivanova,Marketing
```
#### Шаг 2: Скрипт массового создания
Запусти этот скрипт в PowerShell ISE или просто в консоли (от администратора).
PowerShell
```powershell
# 1. Temp password for all users
$DefaultPassword = ConvertTo-SecureString "Start2025!" -AsPlainText -Force

# 2. Read CSV (Loop)
Import-Csv "C:\users.csv" | ForEach-Object {

    # Create full info
    $FullName = "$($_.FirstName) $($_.LastName)"
    $UPN = "$($_.LogonName)@vbo.local"  # <-- Change own Domen!!!
    
    # 3. Create user
    New-ADUser `
        -Name $FullName `
        -GivenName $_.FirstName `
        -Surname $_.LastName `
        -SamAccountName $_.LogonName `
        -UserPrincipalName $UPN `
        -Path "OU=IT-Dept,DC=vbo,DC=local" ` # <-- ПОМЕНЯЙ путь к OU
        -AccountPassword $DefaultPassword `
        -Enabled $true `
        -ChangePasswordAtLogon $true `  # <-- Change Password at first logon
        -Department $_.Department

    Write-Host "User $FullName was created." -ForegroundColor Green
}
```
#### Разбор важных параметров:
- `-ChangePasswordAtLogon $true`: Это ключевой параметр. Когда Ханс Мюллер впервые сядет за компьютер и введет `Start2025!`, Windows сразу скажет: _"Пароль пользователя должен быть изменен перед первым входом в систему"_. 
- `-AccountPassword $DefaultPassword`: Мы передаем заранее зашифрованный объект пароля, а не просто текст.

## "Общая папка для отдела" (Network Drive)

**Сценарий:** Начальник звонит и говорит: _"Виталий, сделай так, чтобы у всех сотрудников IT-отдела при входе автоматически появлялся сетевой диск **Z:** с документами"_.
Как программист, ты оценишь это: мы напишем "правило" один раз, и оно применится ко всем объектам класса "IT-User".
### Шаг 1: Создаем общую папку на Сервере
Сначала нам нужно создать то, _что_ мы будем подключать.
1. На Сервере (`SRV-DC01`) открой Проводник, зайди на диск `C:`.
2. Создай папку `CompanyData`.
3. Нажми правой кнопкой -> **Properties** (Свойства) -> вкладка **Sharing** (Доступ).
4. Нажми **Advanced Sharing** -> поставь галочку **Share this folder**.
5. Нажми **Permissions** (Разрешения).
    - Убедись, что для `Everyone` (Все) стоит галочка **Read** (или Change, если хочешь разрешить запись).
6. Нажми OK, OK, Close.
7. **Важно:** Запомни сетевой путь. Обычно это `\\SRV-DC01\CompanyData`.
### Шаг 2: Создаем Политику (GPO)
1. В **Server Manager** -> **Tools** -> **Group Policy Management**.
2. Разверни дерево слева: `Forest` -> `Domains` -> `vbo.local`.
3. Найди свою папку (OU) `IT-Dept` (где лежит твой юзер Ханс).
4. Нажми на неё **ПРАВОЙ** кнопкой -> **Create a GPO in this domain, and Link it here...**.
5. Назови политику: `GPO_Map_Drive_Z`.
6. Теперь политика создана, но пуста. Нажми на неё в списке **ПРАВОЙ** кнопкой -> **Edit** (Изменить).
### Шаг 3: Настраиваем диск (The Config)
Откроется редактор политик. Тут тысячи настроек. Нам нужна конкретная.
1. Иди по пути: **User Configuration** (Конфигурация пользователя) -> **Preferences** (Настройка) -> **Windows Settings** (Конфигурация Windows) -> **Drive Maps** (Сопоставления дисков).
2. В пустом поле справа нажми **ПРАВОЙ** кнопкой -> **New** -> **Mapped Drive**.
3. Настройки:
    - **Action:** `Update` (Обновить — самый безопасный вариант).
    - **Location:** `\\SRV-DC01\CompanyData` (путь к папке из Шага 1).
    - **Reconnect:** Поставь галочку (чтобы диск не пропадал после перезагрузки).
    - **Label:** Напиши `Company Data` (так диск будет называться у юзера).
    - **Drive Letter:** Выбери `Z:`.
4. Жми OK. Закрой все окна редактора.
### Шаг 4: Тест (Deployment)
Политики обновляются не мгновенно (обычно раз в 90 минут). Но мы форсируем это.
1. Иди на **Windows 11** (клиент).
2. Войди под своим пользователем.
3. Открой командную строку (CMD) или PowerShell.
4. Введи команду админа-джедая: `gpupdate /force` _(Она заставит компьютер немедленно стянуть новые правила с сервера)._
5. Когда напишет "Successfully completed", открой **Этот компьютер (This PC)**.
**Результат:** Если ты видишь в "Сетевых расположениях" диск **Z: (Company Data)** — поздравляю! Ты только что автоматизировал рутину.
