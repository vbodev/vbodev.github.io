Установка Windows GUI:
1. Скачай Zabbix Agent 2 (MSI):
	[Zabbix agents](https://www.zabbix.com/download_agents)
2. Запусти установку.
3. Самый важный момент (Configuration):
    - **Host name:** имя клиента.
    - **Zabbix server IP:** Впиши IP твоего сервера Zabbix
    - **Server or Proxy for active checks:** Тоже впиши IP твоего сервера Zabbix
4. Жми Next -> Install.

Файл настроек C:\Program Files\Zabbix Agent\zabbix_agentd.conf:
	Server=server ip
	ServerActive=server ip
	Hostname=Agent Name
