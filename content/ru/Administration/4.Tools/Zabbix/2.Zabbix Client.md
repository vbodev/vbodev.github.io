### Windows GUI:
1. Скачай Zabbix Agent 2 (MSI):
	[Zabbix agents](https://www.zabbix.com/download_agents)
2. Запусти установку.
3. Самый важный момент (Configuration):
    - **Host name:** имя клиента.
    - **Zabbix server IP:** Впиши IP твоего сервера Zabbix
    - **Server or Proxy for active checks:** Тоже впиши IP твоего сервера Zabbix
4. Жми Next -> Install.

Файл настроек C:\Program Files\Zabbix Agent\zabbix_agentd.conf:
	Server=192.168.56.21
	ServerActive=192.168.56.21
	Hostname=Agent Name
### Windows Core:

```bash
Invoke-WebRequest -Uri "https://cdn.zabbix.com/zabbix/binaries/stable/7.0/7.0.23/zabbix_agent-7.0.23-windows-amd64-openssl.msi" -OutFile "zabbix_agent.msi"
```

```bash
msiexec /i zabbix_agent.msi /qn `
  SERVER="192.168.56.21" `
  SERVERACTIVE="192.168.56.21" `
  HOSTNAME="SRV-DC02" `
  INTERFACE="127.0.0.1" `
  PORT=10050 `
  ENABLEPATH=1
```

### Linux (Ubuntu Server, Debian Server)

```bash
wget https://repo.zabbix.com/zabbix/7.0/ubuntu/pool/main/z/zabbix-release/zabbix-release_7.0-2+ubuntu24.04_all.deb
sudo dpkg -i zabbix-release_7.0-2+ubuntu24.04_all.deb
```

```bash
sudo apt update
sudo apt install zabbix-agent
```

```bash
sudo nano /etc/zabbix/zabbix_agentd.conf
```

```Plaintext
Server= <>
ServerActive= <>
Hostname= <>
```

```bash
sudo systemctl restart zabbix-agent
sudo systemctl enable zabbix-agent
sudo systemctl status zabbix-agent
```
