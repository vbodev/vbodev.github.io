## Установка (Debian, PostgreSQL, Apache)

#### Установка самого Zabbix:
```bash
sudo wget https://repo.zabbix.com/zabbix/7.0/debian/pool/main/z/zabbix-release/zabbix-release_latest_7.0+debian13_all.deb  
sudo dpkg -i zabbix-release_latest_7.0+debian13_all.deb  
sudo apt update
sudo apt install zabbix-server-pgsql zabbix-frontend-php php8.4-pgsql zabbix-apache-conf zabbix-sql-scripts zabbix-agent
```
#### Убедись, что база данных установлена:
```bash
sudo apt update 
sudo apt install postgresql -y 
sudo systemctl start postgresql 
sudo systemctl enable postgresql
```
#### Создаем пользователя zabbix:
```bash
sudo -u postgres createuser --pwprompt zabbix
```
#### Создаем саму базу данных:
```bash
sudo -u postgres createdb -O zabbix zabbix
```
#### Импорт начальных данных:
```bash
zcat /usr/share/zabbix-sql-scripts/postgresql/server.sql.gz | sudo -u zabbix psql zabbix
```
#### Открыть файл на редактирование:
```bash
sudo nano /etc/zabbix/zabbix_server.conf
```
#### Найти строку, раскомментировать и вписать пароль:
```conf
DBPassword=password
```
#### Запуск:
```bash
sudo systemctl restart zabbix-server zabbix-agent apache2
sudo systemctl enable zabbix-server zabbix-agent apache2
```
#### Зайти на страницу в браузере:
```
http://ipaddress/zabbix
```
#### Мастер настройки (Setup Wizard) 🧙‍♂️
Ты увидишь приветственное окно "Welcome to Zabbix". Жми **Next step**.
1. **Check of pre-requisites:** Тут все должно быть **OK** (зеленым). Жми **Next**.
2. **Configure DB connection (Важный момент!):** 
    - **Database type:** Выбери **PostgreSQL** (ты же его ставил).
    - **Database host:** `localhost`
    - **Database name:** `zabbix`
    - **User:** `zabbix`
    - **Password:** введи тот пароль, который ты задавал при создании базы (мы договаривались на `password`).
    - Жми **Next**.
3. **Settings:** Тут можно ничего не менять. Жми **Next**.
4. **Summary:** Просто жми **Next**, затем **Finish**.
#### Вход в систему (Login) 🔑
После настройки тебя перекинет на окно входа. Стандартные пароли (важен регистр букв!):
- **Username:** `Admin` (Обязательно с большой буквы **A**)
- **Password:** `zabbix` (Все маленькие)
Вводи и нажимай **Sign in**.
