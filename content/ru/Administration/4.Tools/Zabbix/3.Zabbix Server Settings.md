Возвращайся в Zabbix Server, веб интерфейс:
1. В меню слева: **Data collection** (Сбор данных) -> **Hosts** (Узлы сети).
2. Справа сверху кнопка: **Create host** (Создать узел).
3. Заполняем карточку:
    - **Host name:** `Zabbix Agent Name` (Точь-в-точь как ты писал при установке агента!).
    - **Templates:** Начни вводить `Windows` и выбери **Windows by Zabbix agent** (стандартный шаблон).
    - **Host groups:** Выбери, например, `Discovered hosts` или создай новую `Lab Servers`.
    - **Interfaces:** Нажми **Add** -> **Agent**.
        - **IP address:** Введи IP твоего Zabbix Agent-а.
        - **DNS name:** оставь пустым.
        - **Port:** `10050` (не меняй).
4. Жми синюю кнопку **Add**.

**Смотреть ошибки в логе на сервере:**
```bash
tail -f /var/log/zabbix/zabbix_server.log | grep "Error"
```
**Используемые порты:** 
```
10050/10051
```
