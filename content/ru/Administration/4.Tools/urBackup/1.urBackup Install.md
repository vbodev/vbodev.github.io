## Порты

**На сервере urBackup:**

- **55413/TCP** — FastCGI для web interface.
- **55414/TCP** — обычный HTTP web interface.
- **55415/TCP** — для **Internet clients**. Нужен, если клиент подключается не как локальный LAN-клиент, а через Internet mode / NAT.
- **35623/UDP** — UDP broadcast для обнаружения клиентов.

**На клиенте urBackup:**

- **35621/TCP** — передача файлов при file backup.
- **35622/UDP** — discovery по UDP broadcast.
- **35623/TCP** — команды и image backup.

Если тебе нужно **что открыть в OPNsense между сервером и клиентом**, то практический минимум такой:

- **Server → Client:** `35621/TCP`, `35623/TCP`
- **Server → Client:** `35622/UDP` для discovery в локальной сети
- **Client → Server:** `55414/TCP`
- **Client → Server:** `55415/TCP` только если используешь **Internet clients**
- **Server → LAN broadcast:** `35623/UDP` для автообнаружения клиентов.

Важный момент: urBackup автоматически обнаруживает клиентов, когда сервер и клиенты находятся **в одной подсети**; это прямо описано в руководстве.
