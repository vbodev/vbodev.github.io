## Server

### Шаг 1. Скачиваем образ (Ubuntu Server) 💿

Разработчики Wazuh больше всего любят Ubuntu. Давай не будем спорить и поставим её, так будет меньше проблем с зависимостями.
1. Скачай **Ubuntu Server 24.04 LTS** (или 22.04).
    - Ссылка: [Ubuntu Server Download](https://ubuntu.com/download/server) (Green button "Download Ubuntu Server 24.04 LTS").
### Шаг 2. Установка ОС (Быстрая) ⚡

1. Запусти установку Ubuntu.    
2. **Profile setup (Твой юзер):**
    - **Your name:** `Vitaliy`
    - **Server name:** `wazuh-server`
    - **Username:** `user` (или как тебе удобно)
    - **Password:** Придумай простой.
3. **Featured Server Snaps:** Ничего не выбирай, просто жми Done.
4. Жди окончания установки (`Install complete!`), потом выбери **Reboot Now**.
5. Установить:
```bash
sudo apt install openssh-server
```
### Шаг 4. Установка Wazuh (Магия одной строки) 🪄

Когда сервер загрузится, войди (логин/пароль).
```bash
curl -sO https://packages.wazuh.com/4.10/wazuh-install.sh && sudo bash ./wazuh-install.sh -a
```
🚀 **Процесс пошел!** Скрипт сам скачает Indexer (базу), Server (мозги) и Dashboard (веб-интерфейс), сгенерирует сертификаты и пароли. Это займет от 5 до 15 минут.
### Финал установки 🏁
Когда в консоли перестанут бежать строки, скрипт напишет тебе **ЖИРНЫМ** текстом:
- **User:** `admin`
- **Password:** `какой-то-очень-длинный-пароль`
**ОБЯЗАТЕЛЬНО** скопируй и сохрани этот пароль в блокнот прямо сейчас! Восстановить его сложно.

**Используемые порты:**
```
1514/1515
```
