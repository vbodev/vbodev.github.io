## Шаг 0: Установка🛑
Microsoft продает ноутбуки с Windows 11 **Home**. Версия **Home НЕ умеет вступать в домен**. Эта функция вырезана. Тебе нужна версия **Pro**, **Enterprise** или **Education**.
1. Внутри твоей новой виртуалки Windows 11 нажми `Win + Pause` (или зайди в Параметры -> Система -> О системе).
2. Посмотри строку **Выпуск (Edition)**.
    - Если там **Pro / Enterprise / Education** — идем дальше.
    - Если там **Home** — увы, эту виртуалку придется удалить и скачать правильный образ (Enterprise Evaluation с сайта Microsoft), иначе ничего не выйдет.
Если версия правильная, вот твой алгоритм. Сейчас произойдет магия соединения.
## Шаг 1: Настройка "проводов" (VirtualBox Network)
Чтобы клиент увидел сервер, они должны быть в одной сети.
1. Выключи (или сверни) виртуалку Win 11. 
2. Зайди в настройки этой машины в VirtualBox -> **Сеть (Network)**.
3. Тип подключения: выбери **Сетевой мост (Bridged Adapter)**.
    - _Важно:_ Точно так же, как мы делали для Сервера. Теперь они оба "сидят" на твоем домашнем роутере и могут пинговать друг друга.
## Шаг 2: Настройка DNS (Самый важный шаг!) 🧠
Компьютер не знает, что такое `vbo.local`. Об этом знает только твой Сервер. Поэтому мы должны сказать Windows 11: _"Если ищешь адреса, спрашивай у Сервера, а не у Гугла"_.
1. Включи Windows 11.
2. Нажми `Win + R`, введи `ncpa.cpl` (Сетевые подключения).
3. Правой кнопкой на адаптер Ethernet -> **Свойства**.
4. Найди **IP версии 4 (TCP/IPv4)** -> Свойства.
5. Настройки IP оставь автоматическими (получит от роутера), А ВОТ DNS ИЗМЕНИ:
    - Переключи на **"Использовать следующие адреса DNS-серверов"**.
    - **Предпочитаемый DNS-сервер:** Впиши **IP-адрес твоего Windows Server** (тот, который мы делали статическим, например `192.168.0.200`).
6. Нажми ОК.

**Проверка связи:** Открой командную строку (cmd) в Windows 11 и напиши: `ping vbo.local` (Подставь имя своего домена).
- Если пинг пошел (Ответ от...) — **ПОБЕДА**. Сеть настроена.
- Если "Не удалось обнаружить узел" — проверяй IP адреса и выключи брандмауэр (Firewall) на сервере для теста.
## Шаг 3: Вступление в Домен (Joining the Domain)
Теперь самое приятное.
1. В Windows 11 нажми `Win + R`, введи `sysdm.cpl` (Свойства системы).
2. Нажми кнопку **Изменить (Change)**.
3. Внизу переключи точку с "Рабочей группы" на **Домен (Domain)**.
4. Впиши имя твоего домена: `vbo.local` (или просто `corp`).
5. Жми ОК.
6. Появится окно ввода логина/пароля.
    - Сюда нужно ввести данные **Администратора ДОМЕНА** (того самого, с сервера).
    - Логин: `Administrator`
    - Пароль: Тот сложный пароль сервера.
7. Если все верно, ты увидишь заветное сообщение: **"Добро пожаловать в домен vbo.local"**.
## Шаг 4: Вход под сотрудником
1. Перезагрузи Windows 11 (он сам попросит).
2. На экране входа выбери **"Другой пользователь" (Other User)**.
3. Вводи данные созданного тобой ранее Ханса или Анны:
    - Логин: `h.muster` (или `h.muster@vbo.local`)
    - Пароль: `Start2025!` (или какой ты там задал).    
4. Если ты ставил галочку "Сменить пароль", Windows 11 тут же попросит придумать новый.
**Итог:** Как только ты увидишь рабочий стол Windows 11 под логином `h.muster`, можешь считать себя Junior Admin-ом. Ты собрал полную схему "Клиент-Сервер".
