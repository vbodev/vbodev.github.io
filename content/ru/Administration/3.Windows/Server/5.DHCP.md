**Проблема:** Сейчас на Windows 11 ты прописывал IP и DNS вручную. Если у тебя 100 компьютеров, ты сойдешь с ума. А если ты оставишь настройки "Автоматически" при текущем подключении (Сетевой мост), то IP выдаст твой домашний роутер. Но роутер _не знает_, что DNS-сервер — это твой `SRV-DC01`. В итоге компьютер получит интернет, но "потеряет" домен.
**Задача:** Сделать так, чтобы Твой Сервер сам раздавал IP-адреса и правильные настройки всем, кто подключается к сети.

⚠️ **ВАЖНЫЙ МОМЕНТ ПЕРЕД НАЧАЛОМ (Network Isolation)** ⚠️ Так как мы сейчас включим свой DHCP-сервер, если оставить настройки VirtualBox в режиме "Сетевой мост" (Bridged), твой учебный сервер может начать раздавать IP-адреса твоему телефону, телевизору или ноутбуку жены в твоей домашней сети. Это вызовет конфликт.
Поэтому мы сначала **изолируем** лабораторию. Мы создадим виртуальный провод, который соединяет _только_ Сервер и Клиент, и отключим их от домашнего Wi-Fi.
### Шаг 1: Изоляция сети (VirtualBox)
1. Выключи обе виртуальные машины (Сервер и Windows 11).
2. Зайди в настройки **Сервера** -> **Сеть**.
    - Тип подключения: измени с "Сетевой мост" на **"Внутренняя сеть" (Internal Network)**.
    - Имя: `intnet` (оставь по умолчанию).
3. Зайди в настройки **Windows 11** -> **Сеть**.
    - Сделай то же самое: **"Внутренняя сеть" (Internal Network)**.
4. Запусти **Сервер**.
    - _Примечание:_ Интернета на сервере теперь не будет. Это нормально для безопасной внутренней среды.
### Шаг 2: Установка роли DHCP
1. На Сервере открой **Server Manager**.
2. **Manage** -> **Add Roles and Features**.
3. Жми Next, пока не увидишь список ролей.
4. Поставь галочку: **DHCP Server**.
    - Согласись на добавление фич (Add Features).
5. Жми Next до конца и **Install**.
### Шаг 3: Настройка DHCP (Post-deployment)
1. После установки в Server Manager снова нажми на **желтый треугольник** ⚠️.
2. Нажми **"Complete DHCP configuration"**.
3. Next -> Введи учетные данные (просто нажми **Commit**, так как ты уже админ) -> Close.
### Шаг 4: Создание Области (Scope)
Теперь надо сказать серверу, _какие_ адреса он имеет право раздавать.
1. **Tools** -> **DHCP**.
2. Разверни: `SRV-DC01` -> `IPv4`.
3. Нажми правой кнопкой на **IPv4** -> **New Scope** (Новая область).
4. **Name:** `Office-Network` (или любое другое).
5. **IP Address Range:**
    - Start IP: `192.168.0.10` (начнем раздавать с 10-го).
    - End IP: `192.168.0.100` (хватит на 90 компов).
    - _Важно:_ Убедись, что статический IP самого сервера (`192.168.0.200` или какой у тебя был) **НЕ** попадает в этот диапазон! Иначе будет конфликт.
    - Length/Subnet mask: `24` / `255.255.255.0`.
6. **Add Exclusions:** Просто жми Next (если не хочешь исключать отдельные IP внутри диапазона).
7. **Lease Duration:** Оставь 8 дней. Next.
8. **Configure DHCP Options:** Выбери **"Yes, I want to configure these options now"**.
    - Это самое важное! Тут мы передаем настройки клиентам.
9. **Router (Default Gateway):** Так как интернета у нас в "изолированной" сети нет, это поле можно оставить пустым. Или впиши IP сервера (`192.168.0.200`), чисто формально. Жми Next.
10. **Domain Name and DNS Servers:**
    - Parent domain: `corp.vitaliy.local` (должен стоять сам).
    - IP address: Там должен уже стоять IP твоего сервера. Если нет — впиши и нажми Add. Жми Next.
11. **WINS:** Пропускаем (Next).
12. **Activate Scope:** Выбери **"Yes, I want to activate this scope now"**. Finish.
### Шаг 5: Проверка на Клиенте (Moment of Truth)
1. Запусти **Windows 11**.
2. Зайди в настройки сетевого адаптера (`ncpa.cpl`).
3. Свойства IPv4 -> Переключи **ВСЁ** на **"Получить IP-адрес автоматически"** и **"Получить адрес DNS-сервера автоматически"**.
4. Жми ОК.
5. Открой командную строку (CMD).
6. Введи: `ipconfig /all`

**Что ты должен увидеть:**
- **DHCP Enabled:** Yes
- **IPv4 Address:** Что-то типа `192.168.0.10` (первый свободный из твоего пула).
- **DNS Servers:** IP твоего сервера (`192.168.0.200`).
- **Connection-specific DNS Suffix:** `corp.vitaliy.local`.
