### Шаг 0: Сделай "Снимок" (Snapshot) — Правило №1
Ты админ. Админы параноики. Прежде чем что-то менять, мы сохраняемся.
1. В окне VirtualBox (сверху): **Machine (Машина) -> Take Snapshot (Сделать снимок)**.
2. Назови: `Clean Install`.
3. _Теперь, если ты что-то сломаешь, ты сможешь откатиться сюда за 2 секунды._
### Шаг 1: Правильное имя (Identity)
По умолчанию сервер называется `WIN-394857...`. Это непрофессионально.
1. В Windows Server нажми `Win + X` -> **System**.
2. Нажми **Rename this PC (Advanced)**.
3. Введи имя: `SRV-DC01` (Стандарт: SRV = Сервер, DC = Domain Controller, 01 = первый).
4. Нажми OK. **Перезагрузись.**
### Шаг 2: Статический IP (Static IP)
Сервер не может иметь "плавающий" IP-адрес. Клиенты (компьютеры сотрудников) должны знать точный адрес "Босса". _Как программист, представь, что ты хардкодишь адрес базы данных в конфиге._
1. В VirtualBox убедись, что в настройках сети стоит **"Сетевой мост" (Bridged Adapter)** — так сервер получит IP от твоего домашнего роутера и будет "как живой" в твоей домашней сети.
2. В Windows Server нажми `Win + R`, введи `ncpa.cpl` (это быстрая команда открыть сетевые адаптеры).
3. Правой кнопкой на адаптер -> **Properties**.
4. Выбери **IPv4** -> Properties.
5. Переключи на **"Use the following IP address"**.
    - _Чтобы узнать, какие цифры писать:_ На хост-машине (твоем обычном компе) открой командную строку, напиши `ipconfig`. Посмотри свой IP и Gateway (Шлюз).
    - _Пример:_ Если твой роутер `192.168.0.1`, то серверу дай:
        - **IP address:** `192.168.0.200` (выбери высокий номер, чтобы не совпал с телефоном).
        - **Subnet mask:** `255.255.255.0` (сама встанет).
        - **Default Gateway:** `192.168.0.1` (IP твоего роутера).
        - **DNS:** `127.0.0.1` (ОЧЕНЬ ВАЖНО! Сервер будет спрашивать сам себя, так как он сам станет DNS-сервером).
### Шаг 3: Установка роли AD DS (Инсталляция)
1. Открой **Server Manager** (он обычно открыт сам).
2. По центру нажми **"Add roles and features"**.
3. Жми Next, Next, Next (выбираем наш сервер `SRV-DC01`).
4. В списке ролей поставь галочку напротив: **Active Directory Domain Services**.
    - Он спросит "Добавить фичи?" — Жми **Add Features**.
5. Жми Next до конца и **Install**.
6. _Жди окончания полоски._
### Шаг 4: "Повышение" сервера (Configuration)
Установка роли — это просто копирование файлов. Теперь нужно активировать.
1. В Server Manager сверху справа появится **желтый треугольник** ⚠️ (флажок). Нажми на него.
2. Нажми ссылку: **"Promote this server to a domain controller"**.
3. Откроется мастер настройки. Это самый важный момент!
    - Выбери опцию: **Add a new forest** (Добавить новый лес). Мы создаем новую организацию с нуля.
    - **Root domain name:** Придумай название. Для локальных тестов используют `.local` или `.lan`.
        - Напиши: `vbo.local` (или любое другое).
4. Жми Next.
5. Придумай пароль для DSRM (режим восстановления). Введи тот же, что и у админа, чтобы не забыть.
6. Жми Next, Next, Next (на предупреждение про DNS не обращай внимания).
7. Он проверит "Prerequisites". Если все зеленые галочки — жми **Install**.
8. Сервер сам перезагрузится. **Внимание:** Первая загрузка будет долгой (минут 5-10), он создает базу данных.
