## Установка Windows Server 2022 на VirtualBox

### Шаг 0: Подготовка
1. Установка **Oracle VirtualBox**.
2. Скачай ISO-образ: `Windows Server 2022 Evaluation ISO download`.
### Шаг 1: Создание виртуальной машины
1. Запусти VirtualBox -> Кнопка **"Создать" (New)**.
2. **Имя:** `WinServer2022`. **Папка:** где есть место (нужно ~30 ГБ). **Образ ISO:** выбери скачанный файл.
3. **Важно:** Поставь галочку _"Пропустить автоматическую установку"_ (Skip Unattended Installation), чтобы контролировать процесс.
4. **Hardware:**
    - RAM: Минимум **4096 MB** (4 ГБ).
    - CPU: **2 vCPU**.
5. **Hard Disk:** Создай новый виртуальный диск, **50 ГБ** достаточно.
### Шаг 2: Установка Windows (Самый важный момент!)
1. Запусти виртуалку. Начнется загрузка с ISO.
2. Выбери язык (English или German, лучше English для обучения, но в Австрии часто немецкие сервера).
3. Нажми "Install Now".
4. 🚩 **КРИТИЧЕСКИЙ МОМЕНТ:** Тебе предложат выбор версии.
    - Выбери: **Windows Server 2022 Standard Evaluation (Desktop Experience)**.
    - _Почему:_ Если выберешь просто "Standard Evaluation" (без слов Desktop Experience), установится версия **Core** — это просто черная консоль без мышки и окон. Для новичка это шок. Тебе нужен графический интерфейс (GUI).
5. Выбери "Custom: Install Windows only (advanced)". Выбери диск и жми Next.
### Шаг 3: Первичная настройка
1. После перезагрузки он попросит задать пароль для пользователя `Administrator`. Придумай сложный (например: `Start2026!`).
2. Ты увидишь рабочий стол. Сразу запустится **Server Manager** (Диспетчер серверов) — это твоя главная панель.
### Шаг 4: Установка Guest Additions (чтобы экран был нормальным)
1. В меню окна VirtualBox сверху: **Устройства (Devices) -> Подключить образ диска Дополнений гостевой ОС (Insert Guest Additions CD image)**.
2. Внутри Windows Server зайди в "This PC", открой CD-диск и запусти установщик (`VBoxWindowsAdditions.exe`).
3. Установи, перезагрузись. Теперь экран можно растягивать, и буфер обмена будет работать.
