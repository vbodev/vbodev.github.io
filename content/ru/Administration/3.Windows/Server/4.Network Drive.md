**Сценарий:** Начальник звонит и говорит: _"Виталий, сделай так, чтобы у всех сотрудников IT-отдела при входе автоматически появлялся сетевой диск **Z:** с документами"_.
Как программист, ты оценишь это: мы напишем "правило" один раз, и оно применится ко всем объектам класса "IT-User".
### Шаг 1: Создаем общую папку на Сервере
Сначала нам нужно создать то, _что_ мы будем подключать.
1. На Сервере (`SRV-DC01`) открой Проводник, зайди на диск `C:`.
2. Создай папку `CompanyData`.
3. Нажми правой кнопкой -> **Properties** (Свойства) -> вкладка **Sharing** (Доступ).
4. Нажми **Advanced Sharing** -> поставь галочку **Share this folder**.
5. Нажми **Permissions** (Разрешения).
    - Убедись, что для `Everyone` (Все) стоит галочка **Read** (или Change, если хочешь разрешить запись).
6. Нажми OK, OK, Close.
7. **Важно:** Запомни сетевой путь. Обычно это `\\SRV-DC01\CompanyData`.
### Шаг 2: Создаем Политику (GPO)
1. В **Server Manager** -> **Tools** -> **Group Policy Management**.
2. Разверни дерево слева: `Forest` -> `Domains` -> `vbo.local`.
3. Найди свою папку (OU) `IT-Dept` (где лежит твой юзер Ханс).
4. Нажми на неё **ПРАВОЙ** кнопкой -> **Create a GPO in this domain, and Link it here...**.
5. Назови политику: `GPO_Map_Drive_Z`.
6. Теперь политика создана, но пуста. Нажми на неё в списке **ПРАВОЙ** кнопкой -> **Edit** (Изменить).
### Шаг 3: Настраиваем диск (The Config)
Откроется редактор политик. Тут тысячи настроек. Нам нужна конкретная.
1. Иди по пути: **User Configuration** (Конфигурация пользователя) -> **Preferences** (Настройка) -> **Windows Settings** (Конфигурация Windows) -> **Drive Maps** (Сопоставления дисков).
2. В пустом поле справа нажми **ПРАВОЙ** кнопкой -> **New** -> **Mapped Drive**.
3. Настройки:
    - **Action:** `Update` (Обновить — самый безопасный вариант).
    - **Location:** `\\SRV-DC01\CompanyData` (путь к папке из Шага 1).
    - **Reconnect:** Поставь галочку (чтобы диск не пропадал после перезагрузки).
    - **Label:** Напиши `Company Data` (так диск будет называться у юзера).
    - **Drive Letter:** Выбери `Z:`.
4. Жми OK. Закрой все окна редактора.
### Шаг 4: Тест (Deployment)
Политики обновляются не мгновенно (обычно раз в 90 минут). Но мы форсируем это.
1. Иди на **Windows 11** (клиент).
2. Войди под своим пользователем.
3. Открой командную строку (CMD) или PowerShell.
4. Введи команду админа-джедая: `gpupdate /force` _(Она заставит компьютер немедленно стянуть новые правила с сервера)._
5. Когда напишет "Successfully completed", открой **Этот компьютер (This PC)**.
**Результат:** Если ты видишь в "Сетевых расположениях" диск **Z: (Company Data)** — поздравляю! Ты только что автоматизировал рутину.
