### **UrBackup-Server**
#### **Linux**

Hauptprotokoll über systemd:
```bash
journalctl -u urbackupsrv -f

journalctl -u urbackupsrv -n 200
```
Wenn der Dienst anders aufgerufen wird, prüfen Sie:
```bash
systemctl list-units | grep -i urbackup
```
#### **Windows**

Normalerweise schauen Sie:
   - `C:\Program Files\UrBackupServer\`
   - `C:\Program Files\UrBackupServer\urbackup.log`
   - **Ereignisanzeige** → Windows-Protokolle → Anwendung
   - oder Protokolle, die mit dem UrBackup-Dienst verbunden sind

### **UrBackup-Client**

#### **Linux**

Über systemd:
```bash
journalctl -u urbackupclientbackend -f

journalctl -u urbackupclientbackend -n 200
```
#### **Windows**

Normalerweise befinden sich Client-Protokolle in:
 - `C:\Program Files\UrBackup\`
 - `C:\Program Files\UrBackup\debug.log`
 - `C:\Program Files\UrBackup\urbackup.log`
 - **Ereignisanzeige** → Windows-Protokolle → Anwendung

### **Dienststatus prüfen**
#### **Linux**
```bash
systemctl status urbackupsrv  
systemctl status urbackupclientbackend
```
#### **Windows PowerShell**


```Powershell
Get-Service *urbackup*
```
