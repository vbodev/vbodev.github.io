## Server

### Schritt 1. Image herunterladen (Ubuntu Server) 💿

Wazuh-Entwickler bevorzugen Ubuntu. Folgen wir ihrem Rat, damit es weniger Abhängigkeitsprobleme gibt.
1. **Ubuntu Server 24.04 LTS** (oder 22.04) herunterladen.
    - Link: [Ubuntu Server Download](https://ubuntu.com/download/server) (Grüne Schaltfläche "Download Ubuntu Server 24.04 LTS").
### Schritt 2. OS installieren (Schnell) ⚡

1. Ubuntu-Installation starten.
2. **Profile setup (Dein Benutzer):**
    - **Your name:** `Vitaliy`
    - **Server name:** `wazuh-server`
    - **Username:** `user` (oder wie du möchtest)
    - **Password:** Einen einfachen wählen.
3. **Featured Server Snaps:** Nichts auswählen, einfach Done drücken.
4. Ende der Installation abwarten (`Install complete!`), dann **Reboot Now** wählen.
5. Installieren:
```bash
sudo apt install openssh-server
```
### Schritt 4. Wazuh installieren (Magie in einer Zeile) 🪄

Wenn der Server gebootet ist, einloggen (Login/Passwort).
```bash
curl -sO https://packages.wazuh.com/4.10/wazuh-install.sh && sudo bash ./wazuh-install.sh -a
```
🚀 **Prozess gestartet!** Das Skript lädt selbst Indexer (Datenbank), Server (Gehirn) und Dashboard (Web-Interface) herunter, generiert Zertifikate und Passwörter. Das dauert 5 bis 15 Minuten.
### Ende der Installation 🏁
Wenn in der Konsole keine Zeilen mehr laufen, gibt das Skript **FETT** gedruckt aus:
- **User:** `admin`
- **Password:** `ein-sehr-langes-passwort`
Dieses Passwort **UNBEDINGT** sofort kopieren und in den Editor speichern! Es ist schwer zu recovern.

**Verwendete Ports:**
```
1514/1515
```
