Installation:
1. Zabbix Agent 2 (MSI) herunterladen:
	[Zabbix agents](https://www.zabbix.com/download_agents)
2. Installation starten.
3. Der wichtigste Moment (Configuration):
    - **Host name:** Name des Clients.
    - **Zabbix server IP:** IP des Zabbix-Servers eingeben.
    - **Server or Proxy for active checks:** Auch die IP des Zabbix-Servers eingeben.
4. Next -> Install klicken.

Konfigurationsdatei `C:\Program Files\Zabbix Agent\zabbix_agentd.conf`:
	Server=server ip
	ServerActive=server ip
	Hostname=Agent Name
