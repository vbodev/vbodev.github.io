Zurück in das Webinterface des Zabbix Servers gehen:
1. Im linken Menü: **Data collection** (Datenerfassung) -> **Hosts** (Netzwerkknoten).
2. Oben rechts Schaltfläche: **Create host** (Host erstellen).
3. Die Karte ausfüllen:
    - **Host name:** `Zabbix Agent Name` (Exakt so, wie beim Installieren des Agenten angegeben!).
    - **Templates:** `Windows` eintippen und **Windows by Zabbix agent** auswählen (Standardvorlage).
    - **Host groups:** Z.B. `Discovered hosts` auswählen oder eine neue `Lab Servers` erstellen.
    - **Interfaces:** **Add** -> **Agent** klicken.
        - **IP address:** IP deines Zabbix-Agenten eingeben.
        - **DNS name:** Leer lassen.
        - **Port:** `10050` (nicht ändern).
4. Blaue Schaltfläche **Add** klicken.

**Fehler im Server-Log anzeigen:**
```bash
tail -f /var/log/zabbix/zabbix_server.log | grep "Error"
```
**Verwendete Ports:**
```
10050/10051
```
