## Installation (Debian, PostgreSQL, Apache)

#### Zabbix selbst installieren:
```bash
sudo wget https://repo.zabbix.com/zabbix/7.0/debian/pool/main/z/zabbix-release/zabbix-release_latest_7.0+debian13_all.deb  
sudo dpkg -i zabbix-release_latest_7.0+debian13_all.deb  
sudo apt update
sudo apt install zabbix-server-pgsql zabbix-frontend-php php8.4-pgsql zabbix-apache-conf zabbix-sql-scripts zabbix-agent
```
#### Sicherstellen, dass die Datenbank installiert ist:
```bash
sudo apt update 
sudo apt install postgresql -y 
sudo systemctl start postgresql 
sudo systemctl enable postgresql
```
#### Zabbix-Benutzer erstellen:
```bash
sudo -u postgres createuser --pwprompt zabbix
```
#### Die Datenbank selbst erstellen:
```bash
sudo -u postgres createdb -O zabbix zabbix
```
#### Anfangsdaten importieren:
```bash
zcat /usr/share/zabbix-sql-scripts/postgresql/server.sql.gz | sudo -u zabbix psql zabbix
```
#### Datei zum Bearbeiten öffnen:
```bash
sudo nano /etc/zabbix/zabbix_server.conf
```
#### Zeile finden, auskommentieren und Passwort eintragen:
```conf
DBPassword=password
```
#### Starten:
```bash
sudo systemctl restart zabbix-server zabbix-agent apache2
sudo systemctl enable zabbix-server zabbix-agent apache2
```
#### Im Browser die Seite aufrufen:
```
http://ipaddress/zabbix
```
#### Einrichtungsassistent (Setup Wizard) 🧙‍♂️
Das Willkommensfenster "Welcome to Zabbix" erscheint. **Next step** drücken.
1. **Check of pre-requisites:** Hier sollte alles **OK** (grün) sein. **Next** drücken.
2. **Configure DB connection (Wichtig!):**
    - **Database type:** **PostgreSQL** auswählen (das wurde installiert).
    - **Database host:** `localhost`
    - **Database name:** `zabbix`
    - **User:** `zabbix`
    - **Password:** Das Passwort eingeben, das beim Erstellen der Datenbank gesetzt wurde (wir hatten `password` vereinbart).
    - **Next** drücken.
3. **Settings:** Hier nichts ändern. **Next** drücken.
4. **Summary:** Einfach **Next**, dann **Finish** drücken.
#### Im System einloggen (Login) 🔑
Nach der Konfiguration wird zum Anmeldefenster weitergeleitet. Standard-Zugangsdaten (Groß-/Kleinschreibung beachten!):
- **Username:** `Admin` (Unbedingt mit großem **A**)
- **Password:** `zabbix` (Alles klein)
Eingeben und **Sign in** klicken.
