**Problem:** Aktuell hast du IP und DNS auf Windows 11 manuell eingetragen. Bei 100 Computern wirst du verrückt. Und wenn du die Einstellungen auf "Automatisch" lässt (Bridged-Verbindung), vergibt dein Heimrouter die IP. Aber der Router _weiß nicht_, dass der DNS-Server dein `SRV-DC01` ist. Das Ergebnis: Der Computer erhält Internet, aber "verliert" die Domain.
**Aufgabe:** Sorge dafür, dass dein Server selbst IP-Adressen und korrekte Einstellungen an alle Geräte im Netzwerk verteilt.

⚠️ **WICHTIGER HINWEIS VOR DEM START (Netzwerkisolation)** ⚠️ Da wir jetzt unseren eigenen DHCP-Server aktivieren, könnte bei VirtualBox-Modus "Netzwerkbrücke" (Bridged) unser Lernserver anfangen, IP-Adressen an dein Telefon, den Fernseher oder den Laptop deiner Frau in deinem Heimnetz zu vergeben. Das verursacht Konflikte.
Daher **isolieren** wir zuerst das Labor. Wir erstellen eine virtuelle Verbindung, die _nur_ Server und Client verbindet, und trennen sie vom Heim-WLAN.
### Schritt 1: Netzwerkisolation (VirtualBox)
1. Beide virtuellen Maschinen ausschalten (Server und Windows 11).
2. In die Einstellungen des **Servers** -> **Netzwerk** gehen.
    - Verbindungsart: von "Netzwerkbrücke" auf **"Internes Netzwerk" (Internal Network)** ändern.
    - Name: `intnet` (Standard lassen).
3. In die Einstellungen von **Windows 11** -> **Netzwerk** gehen.
    - Dasselbe tun: **"Internes Netzwerk" (Internal Network)**.
4. **Server** starten.
    - _Hinweis:_ Internet ist auf dem Server jetzt nicht mehr verfügbar. Das ist normal für eine sichere interne Umgebung.
### Schritt 2: DHCP-Rolle installieren
1. Auf dem Server **Server Manager** öffnen.
2. **Manage** -> **Add Roles and Features**.
3. Next klicken, bis die Rollenliste erscheint.
4. Haken bei **DHCP Server** setzen.
    - Auf Features hinzufügen (Add Features) klicken.
5. Bis zum Ende Next klicken und **Install**.
### Schritt 3: DHCP konfigurieren (Post-deployment)
1. Nach der Installation im Server Manager erneut auf das **gelbe Dreieck** ⚠️ klicken.
2. **"Complete DHCP configuration"** anklicken.
3. Next -> Anmeldedaten eingeben (einfach **Commit** klicken, da du bereits Admin bist) -> Close.
### Schritt 4: Bereich erstellen (Scope)
Jetzt müssen wir dem Server sagen, _welche_ Adressen er vergeben darf.
1. **Tools** -> **DHCP**.
2. Aufklappen: `SRV-DC01` -> `IPv4`.
3. Rechtsklick auf **IPv4** -> **New Scope** (Neuer Bereich).
4. **Name:** `Office-Network` (oder beliebiger anderer).
5. **IP Address Range:**
    - Start IP: `192.168.0.10` (wir fangen ab der 10. an).
    - End IP: `192.168.0.100` (reicht für 90 Rechner).
    - _Wichtig:_ Sicherstellen, dass die statische IP des Servers selbst (`192.168.0.200`) **NICHT** in diesen Bereich fällt! Sonst gibt es Konflikte.
    - Length/Subnet mask: `24` / `255.255.255.0`.
6. **Add Exclusions:** Einfach Next klicken (wenn keine einzelnen IPs ausgeschlossen werden sollen).
7. **Lease Duration:** 8 Tage lassen. Next.
8. **Configure DHCP Options:** **"Yes, I want to configure these options now"** auswählen.
    - Das ist das Wichtigste! Hier übergeben wir Einstellungen an Clients.
9. **Router (Default Gateway):** Da wir kein Internet in der "isolierten" Umgebung haben, kann das leer bleiben. Oder Server-IP eingeben (`192.168.0.200`). Next.
10. **Domain Name and DNS Servers:**
    - Parent domain: `corp.vitaliy.local` (sollte automatisch stehen).
    - IP address: Server-IP sollte bereits stehen. Wenn nicht — eingeben und Add klicken. Next.
11. **WINS:** Überspringen (Next).
12. **Activate Scope:** **"Yes, I want to activate this scope now"** auswählen. Finish.
### Schritt 5: Test auf dem Client (Moment of Truth)
1. **Windows 11** starten.
2. In die Netzwerkadaptereinstellungen gehen (`ncpa.cpl`).
3. IPv4-Eigenschaften -> **ALLES** auf **"IP-Adresse automatisch beziehen"** und **"DNS-Serveradresse automatisch beziehen"** umschalten.
4. OK klicken.
5. Eingabeaufforderung (CMD) öffnen.
6. Eingeben: `ipconfig /all`

**Was du sehen solltest:**
- **DHCP Enabled:** Yes
- **IPv4 Address:** Etwas wie `192.168.0.10` (erste freie aus deinem Pool).
- **DNS Servers:** IP deines Servers (`192.168.0.200`).
- **Connection-specific DNS Suffix:** `corp.vitaliy.local`.
