## Installation von Windows Server 2022 auf VirtualBox

### Schritt 0: Vorbereitung
1. Installation von **Oracle VirtualBox**.
2. ISO-Image herunterladen: `Windows Server 2022 Evaluation ISO download`.
### Schritt 1: Virtuelle Maschine erstellen
1. VirtualBox starten -> Schaltfläche **"Neu" (New)**.
2. **Name:** `WinServer2022`. **Ordner:** wo Platz ist (~30 GB benötigt). **ISO-Image:** heruntergeladene Datei auswählen.
3. **Wichtig:** Haken bei _"Unbeaufsichtigte Installation überspringen"_ (Skip Unattended Installation) setzen, um den Prozess zu kontrollieren.
4. **Hardware:**
    - RAM: Mindestens **4096 MB** (4 GB).
    - CPU: **2 vCPU**.
5. **Hard Disk:** Neuen virtuellen Datenträger erstellen, **50 GB** reichen.
### Schritt 2: Windows installieren (Der wichtigste Moment!)
1. Virtuelle Maschine starten. Laden von ISO beginnt.
2. Sprache auswählen (Englisch oder Deutsch, besser Englisch zum Lernen, aber in Österreich oft deutsche Server).
3. "Install Now" klicken.
4. 🚩 **KRITISCHER MOMENT:** Eine Versionsauswahl erscheint.
    - Wähle: **Windows Server 2022 Standard Evaluation (Desktop Experience)**.
    - _Warum:_ Wenn du einfach "Standard Evaluation" (ohne Desktop Experience) wählst, wird die **Core**-Version installiert — das ist nur eine schwarze Konsole ohne Maus und Fenster. Für Anfänger ein Schock. Du brauchst die grafische Benutzeroberfläche (GUI).
5. "Custom: Install Windows only (advanced)" wählen. Datenträger auswählen und Next klicken.
### Schritt 3: Erstkonfiguration
1. Nach dem Neustart wird er bitten, ein Passwort für den Benutzer `Administrator` zu setzen. Ein starkes Passwort festlegen (z.B.: `Start2026!`).
2. Der Desktop erscheint. Sofort startet der **Server-Manager** (Serververwaltung) — das ist deine Hauptoberfläche.
### Schritt 4: Guest Additions installieren (für normale Bildschirmgröße)
1. Im VirtualBox-Fenstermenü oben: **Geräte (Devices) -> Gasterweiterungen-CD einlegen (Insert Guest Additions CD image)**.
2. Innerhalb des Windows Servers in "Dieser PC" den CD-Datenträger öffnen und den Installer (`VBoxWindowsAdditions.exe`) starten.
3. Installieren, neu starten. Jetzt kann der Bildschirm skaliert werden und die Zwischenablage funktioniert.
