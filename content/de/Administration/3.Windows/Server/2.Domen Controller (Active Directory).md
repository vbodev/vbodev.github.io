### Schritt 0: Erstelle einen "Snapshot" — Regel Nr. 1
Du bist Admin. Admins sind paranoid. Bevor wir irgendwas ändern, speichern wir.
1. Im VirtualBox-Fenster (oben): **Machine -> Take Snapshot**.
2. Benenne es: `Clean Install`.
3. _Wenn du jetzt etwas kaputtmachst, kannst du in 2 Sekunden hierher zurückrollen._
### Schritt 1: Richtiger Name (Identity)
Standardmäßig heißt der Server `WIN-394857...`. Das ist unprofessionell.
1. In Windows Server `Win + X` drücken -> **System**.
2. **Rename this PC (Advanced)** anklicken.
3. Name eingeben: `SRV-DC01` (Standard: SRV = Server, DC = Domain Controller, 01 = erster).
4. OK klicken. **Neu starten.**
### Schritt 2: Statische IP (Static IP)
Ein Server kann keine "schwimmende" IP-Adresse haben. Clients (Rechner der Mitarbeiter) müssen die genaue Adresse des "Chefs" kennen. _Als Programmierer: Stell dir vor, du hardcodest eine Datenbankadresse in der Konfiguration._
1. In VirtualBox sicherstellen, dass in den Netzwerkeinstellungen **"Netzwerkbrücke" (Bridged Adapter)** gesetzt ist — so bekommt der Server eine IP von deinem Heimrouter und ist "lebendig" in deinem Heimnetz.
2. In Windows Server `Win + R` drücken, `ncpa.cpl` eingeben.
3. Rechtsklick auf den Adapter -> **Properties**.
4. **IPv4** auswählen -> Properties.
5. Auf **"Use the following IP address"** umschalten.
    - _Um zu wissen, welche Zahlen:_ Auf dem Hostrechner Eingabeaufforderung öffnen, `ipconfig` eingeben. Eigene IP und Gateway ansehen.
    - _Beispiel:_ Wenn dein Router `192.168.0.1` ist, gib dem Server:
        - **IP address:** `192.168.0.200` (hohe Zahl wählen, damit es nicht mit dem Telefon übereinstimmt).
        - **Subnet mask:** `255.255.255.0` (erscheint automatisch).
        - **Default Gateway:** `192.168.0.1` (IP deines Routers).
        - **DNS:** `127.0.0.1` (SEHR WICHTIG! Der Server fragt sich selbst, da er selbst DNS-Server wird).
### Schritt 3: AD DS Rolle installieren
1. **Server Manager** öffnen (ist normalerweise von selbst offen).
2. In der Mitte auf **"Add roles and features"** klicken.
3. Next, Next, Next klicken (unseren Server `SRV-DC01` auswählen).
4. In der Rollenliste Haken setzen bei: **Active Directory Domain Services**.
    - Er fragt "Features hinzufügen?" — **Add Features** klicken.
5. Bis zum Ende Next klicken und **Install**.
6. _Auf das Ende der Fortschrittsleiste warten._
### Schritt 4: Server "promoten" (Configuration)
Die Rolleninstallation ist nur Dateikopieren. Jetzt muss aktiviert werden.
1. Im Server Manager oben rechts erscheint ein **gelbes Dreieck** ⚠️ (Flagge). Darauf klicken.
2. Den Link anklicken: **"Promote this server to a domain controller"**.
3. Ein Konfigurationsassistent öffnet sich. Das ist der wichtigste Moment!
    - Option wählen: **Add a new forest** (Neuen Gesamtstruktur hinzufügen). Wir erstellen eine neue Organisation von Grund auf.
    - **Root domain name:** Einen Namen festlegen. Für lokale Tests verwendet man `.local` oder `.lan`.
        - Eingeben: `vbo.local` (oder ein beliebiger anderer).
4. Next klicken.
5. Ein Passwort für DSRM (Wiederherstellungsmodus) festlegen. Das gleiche wie das Admin-Passwort eingeben, um es nicht zu vergessen.
6. Next, Next, Next klicken (die DNS-Warnung ignorieren).
7. Er prüft "Prerequisites". Wenn alle Häkchen grün sind — **Install** klicken.
8. Der Server startet automatisch neu. **Achtung:** Der erste Start wird lang sein (5-10 Minuten), er erstellt die Datenbank.
