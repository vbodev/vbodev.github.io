## Schritt 0: Installation 🛑
Microsoft verkauft Laptops mit Windows 11 **Home**. Die **Home-Version kann NICHT einer Domain beitreten**. Diese Funktion ist herausgeschnitten. Du brauchst die Version **Pro**, **Enterprise** oder **Education**.
1. In deiner neuen Windows 11-VM `Win + Pause` drücken (oder in Einstellungen -> System -> Info gehen).
2. Die Zeile **Edition** ansehen.
    - Wenn dort **Pro / Enterprise / Education** steht — weiter.
    - Wenn dort **Home** steht — leider muss diese VM gelöscht und ein richtiges Image heruntergeladen werden (Enterprise Evaluation von der Microsoft-Website), sonst geht nichts.
Wenn die Version korrekt ist, ist das dein Algorithmus. Jetzt passiert die Magie der Verbindung.
## Schritt 1: "Kabel" konfigurieren (VirtualBox-Netzwerk)
Damit der Client den Server sieht, müssen sie im selben Netzwerk sein.
1. Die Windows 11-VM ausschalten (oder minimieren).
2. In die Einstellungen dieser Maschine in VirtualBox -> **Netzwerk (Network)** gehen.
3. Verbindungsart: **Netzwerkbrücke (Bridged Adapter)** auswählen.
    - _Wichtig:_ Genau wie beim Server. Jetzt sitzen beide an deinem Heimrouter und können sich gegenseitig anpingen.
## Schritt 2: DNS konfigurieren (Der wichtigste Schritt!) 🧠
Der Computer weiß nicht, was `vbo.local` ist. Das weiß nur dein Server. Daher müssen wir Windows 11 sagen: _"Wenn du Adressen suchst, frag beim Server, nicht bei Google"_.
1. Windows 11 starten.
2. `Win + R` drücken, `ncpa.cpl` eingeben (Netzwerkverbindungen).
3. Rechtsklick auf den Ethernet-Adapter -> **Eigenschaften (Properties)**.
4. **IP Version 4 (TCP/IPv4)** finden -> Eigenschaften.
5. IP-Einstellungen automatisch lassen (vom Router erhalten), ABER DNS ÄNDERN:
    - Auf **"Folgende DNS-Serveradressen verwenden"** umschalten.
    - **Bevorzugter DNS-Server:** Die **IP-Adresse deines Windows Servers** eingeben (die statische, z.B. `192.168.0.200`).
6. OK klicken.

**Verbindungstest:** Eingabeaufforderung (cmd) in Windows 11 öffnen und eingeben: `ping vbo.local` (eigenen Domainnamen einsetzen).
- Wenn Ping funktioniert (Antwort von...) — **SIEG**. Das Netzwerk ist konfiguriert.
- Wenn "Host konnte nicht gefunden werden" — IP-Adressen prüfen und die Firewall auf dem Server für den Test deaktivieren.
## Schritt 3: Der Domain beitreten (Joining the Domain)
Jetzt das Angenehmste.
1. In Windows 11 `Win + R` drücken, `sysdm.cpl` eingeben (Systemeigenschaften).
2. Schaltfläche **Ändern (Change)** klicken.
3. Unten den Punkt von "Arbeitsgruppe" auf **Domain** umstellen.
4. Den Domainnamen eingeben: `vbo.local` (oder einfach `corp`).
5. OK klicken.
6. Ein Anmeldefenster erscheint.
    - Hier die Daten des **Domain-Administrators** (vom Server) eingeben.
    - Login: `Administrator`
    - Passwort: Das komplexe Server-Passwort.
7. Wenn alles korrekt ist, erscheint die ersehnte Meldung: **"Willkommen in der Domäne vbo.local"**.
## Schritt 4: Als Mitarbeiter anmelden
1. Windows 11 neu starten (er wird selbst darum bitten).
2. Auf dem Anmeldebildschirm **"Anderer Benutzer" (Other User)** auswählen.
3. Daten des zuvor erstellten Hans oder Anna eingeben:
    - Login: `h.muster` (oder `h.muster@vbo.local`)
    - Passwort: `Start2025!` (oder welches du vergeben hast).
4. Wenn du die Checkbox "Passwort ändern" gesetzt hattest, wird Windows 11 sofort darum bitten, ein neues zu vergeben.
**Fazit:** Sobald du den Windows 11-Desktop unter dem Login `h.muster` siehst, kannst du dich als Junior Admin bezeichnen. Du hast ein vollständiges "Client-Server"-Schema aufgebaut.
