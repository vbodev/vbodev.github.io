## Filterung
```java
List<String> names = List.of("Alice", "Bob", "Carl", "Anna");
List<String> filtered = names.stream()
    .filter(n -> n.startsWith("A"))
    .toList();
System.out.println(filtered); // [Alice, Anna]
```

## Map (Transformation)
```java
List<String> upper = names.stream()
    .map(String::toUpperCase)
    .toList();
System.out.println(upper); // [ALICE, BOB, CARL, ANNA]
```

## Collectors.groupingBy
```java
Map<Integer, List<String>> grouped = names.stream()
    .collect(Collectors.groupingBy(String::length));
System.out.println(grouped);
// {3=[Bob], 4=[Anna], 5=[Alice, Carl]}
```

**Explanation of Choices:**

*   **Filterung:**  Direct translation of "Filtering".
*   **Map (Transformation):**  "Map" is kept in English, and "Transformation" is translated to clarify the function.
*   **Collectors.groupingBy:**  Direct translation of "groupingBy".
*   **// {3=[Bob], 4=[Anna], 5=[Alice, Carl]}**: The comment remains unchanged.
*   The code blocks are preserved exactly as they were, including the `//` comments.
*   The `List.of`, `String::toUpperCase`, `Collectors.groupingBy` are kept as is.
*   The `System.out.println` statements are kept as is.
*   The filenames and Obsidian links are not translated.
*   The technical terminology is kept consistent with standard Java terminology.
