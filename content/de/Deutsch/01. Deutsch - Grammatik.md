### 1. Präsens

#### Использование:
1. Описывает актуальную информацию, выражает то, что происходит в момент речи.
2. Иногда используется в речи о будущем. Указание на будущее или понятно из контекста.
#### Формула образования:
 
|                                                            |
| ---------------------------------------------------------- |
| Verbbasis (Präsens) **+** Ende (-e, -st, -t, -en, -t, -en) |
#### Примеры:

| <span class="brown-bg-tt">Pos1</span> | <span class="brown-bg-tt">Pos2</span> |                   | <span class="brown-bg-tt">Ende</span> |
| ------------------------------------- | ------------------------------------- | ----------------- | ------------------------------------- |
| Ich                                   | heiße                                 | Vitaliy           |                                       |
| Ich                                   | räume                                 | mein Zimmer       | auf                                   |
| Am Freitag                            | kauft                                 | sie im Supermarkt | ein                                   |
### 2. Perfekt

#### Использование:
1. Указание на действие, которое на момент речи завершилось, но результат актуален для настоящего. Употребляется в разговорной речи.
#### Формула образования:

|                                         |         |           |
| --------------------------------------- | ------- | --------- |
| Verbbasis «haben/seine (Präsens) + Ende | **...** | Partizip2 |
#### Примеры:

| <span class="brown-bg-tt">Pos1</span> | <span class="brown-bg-tt">Pos2</span> |                      | <span class="brown-bg-tt">Ende</span> |
| ------------------------------------- | ------------------------------------- | -------------------- | ------------------------------------- |
| Ich                                   | habe                                  | die Hausübung        | gemacht                               |
| Du                                    | bist                                  | nach Paris           | gefahren                              |
| Er                                    | ist                                   | um 11 Uhr nach Hause | gekommen                              |

### 3. Präteritum

#### Использование:
1. Действие, которое произошло в прошлом, но к настоящему моменту завершилось.
#### Формула образования:

|                                   |
| --------------------------------- |
| Verbbasis (Präteritum) **+** Ende |
#### Примеры:

| <span class="brown-bg-tt">Pos1</span> | <span class="brown-bg-tt">Pos2</span> |                         | <span class="brown-bg-tt">Ende</span> |
| ------------------------------------- | ------------------------------------- | ----------------------- | ------------------------------------- |
| Ich                                   | war                                   | Köchin.                 |                                       |
| Du                                    | hattest                               | Frühstück.              |                                       |
| Du                                    | sprachst                              | mit dein Freund gestern |                                       |
| Er                                    | kaufte                                | im Supermarkt           | ein                                   |
### 4. Plusquamperfekt

#### Использование:
1. Действие, которое завершилось до какого-то момента в прошлом.
#### Формула образования:

|                                               |       |           |
| --------------------------------------------- | ----- | --------- |
| Verbbasis haben/seine (Präteritum) **+** Ende | **…** | Partizip2 |
#### Примеры:

| <span class="brown-bg-tt">Pos1</span> | <span class="brown-bg-tt">Pos2</span> |            | <span class="brown-bg-tt">Ende</span> |
| ------------------------------------- | ------------------------------------- | ---------- | ------------------------------------- |
| Du                                    | hattest                               | die Matura | gemacht                               |
| Sie                                   | hatte                                 | die Matura | gemacht                               |
| Du                                    | warst                                 | nach Hause | gekommen                              |
| Er                                    | war                                   | nach Hause | gekommen                              |
### 5. Futur 1

#### Использование:
1. Указывает на действие, которое произойдет в будущем, иногда в контексте твердого намерения или команды.
#### Формула образования:

|                                       |       |               |
| ------------------------------------- | ----- | ------------- |
| Verbbasis werden (Präsens) **+** Ende | **…** | Verbinfinitiv |
#### Примеры:

| <span class="brown-bg-tt">Pos1</span> | <span class="brown-bg-tt">Pos2</span> |            | <span class="brown-bg-tt">Ende</span> |
| ------------------------------------- | ------------------------------------- | ---------- | ------------------------------------- |
| Ich                                   | werde                                 | mein Haus  | bauen                                 |
| Du                                    | wirst                                 | mein Haus  | bauen                                 |
| Er                                    | wird                                  | die Matura | machen                                |
| Ihr                                   | werdet                                | die Matura | machen                                |
### 6. Futur 2

#### Использование:
1. Указывает на действие, которое завершится в будущем, часто к определенному моменту.
#### Формула образования:

|                                       |         |                               |
| ------------------------------------- | ------- | ----------------------------- |
| Verbbasis werden (Präsens) **+** Ende | **...** | Partizip2 + haben (Infinitiv) |
#### Примеры:
* Ich werde mein Haus gebaut haben
* Du wirst mein Haus gebaut haben
