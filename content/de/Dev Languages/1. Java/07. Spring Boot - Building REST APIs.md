## 1. Basis-REST-Controller

```java
@RestController
@RequestMapping("/api/users")
@RequiredArgsConstructor
public class UserController {
    private final UserService service;
    @GetMapping
    public List<UserDto> getAll() {
        return service.allUsers();
    }

    @GetMapping("/{id}")
    public UserDto getById(@PathVariable Long id) {
        return service.getUser(id);
    }

    @PostMapping
    public UserDto create(@Valid @RequestBody UserDto dto) {
        return service.create(dto);
    }

    @DeleteMapping("/{id}")
    public void delete(@PathVariable Long id) {
        service.delete(id);
    }
}
```
📌 Annotationen:
- @RestController = @Controller + @ResponseBody
- @RequestMapping → Basispräfix (/api/users)
- @GetMapping, @PostMapping, @PutMapping, @DeleteMapping
## 2. Validierung (JSR-380 Bean Validation)

📄 DTO:
```java
public record UserDto(
    @NotBlank String name,
    @Email String email,
    @Min(18) int age
) {}
```

📄 Im Controller:
```java
@PostMapping
public UserDto create(@Valid @RequestBody UserDto dto) {
    return service.create(dto);
}
```

📄 Fehlerbehandlung:
```java
@RestControllerAdvice
public class GlobalExceptionHandler {
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<Map<String, String>> handleValidation(MethodArgumentNotValidException ex) {
        Map<String, String> errors = new HashMap<>();
        ex.getBindingResult().getFieldErrors()
                .forEach(e -> errors.put(e.getField(), e.getDefaultMessage()));
        return ResponseEntity.badRequest().body(errors);
    }
}
```
## 3. Fehlerbehandlung (ProblemDetail — Spring 6, RFC 7807)

```java
@RestControllerAdvice
class ApiExceptionHandler {
    @ExceptionHandler(IllegalArgumentException.class)
    ProblemDetail handleIllegalArgument(IllegalArgumentException e) {
        ProblemDetail pd = ProblemDetail.forStatus(HttpStatus.BAD_REQUEST);
        pd.setTitle("Validation failed");
        pd.setDetail(e.getMessage());
        return pd;
    }
}
```

📌 Die JSON-Antwort wird im Format vorliegen:
```json
{
  "type": "about:blank",
  "title": "Validation failed",
  "status": 400,
  "detail": "Invalid email"
}
```
## 4. Paginierung und Sortierung

Spring Data JPA kann selbst:
```java
@GetMapping
public Page<UserDto> all(@RequestParam int page, @RequestParam int size) {
    return repo.findAll(PageRequest.of(page, size, Sort.by("name").ascending()));
}
```

📌 Die JSON-Antwort wird Felder enthalten:
```json
{
  "content": [...],
  "totalPages": 5,
  "totalElements": 100,
  "number": 0,
  "size": 20
}
```
## 5. Filterung (Specification API)

```java
public interface UserRepository extends JpaRepository<User, Long>, JpaSpecificationExecutor<User> {}

@GetMapping("/search")
public List<User> search(@RequestParam(required=false) String name,
                         @RequestParam(required=false) Integer minAge) {
    return repo.findAll((root, query, cb) -> {
        List<Predicate> predicates = new ArrayList<>();
        if (name != null) predicates.add(cb.like(root.get("name"), "%" + name + "%"));
        if (minAge != null) predicates.add(cb.greaterThanOrEqualTo(root.get("age"), minAge));
        return cb.and(predicates.toArray(new Predicate[0]));
    });
}
```
## 6. Hochladen und Herunterladen von Dateien

**Upload**
```java
@PostMapping("/upload")
public String upload(@RequestParam("file") MultipartFile file) throws IOException {
    Path path = Paths.get("uploads/" + file.getOriginalFilename());
    Files.copy(file.getInputStream(), path, StandardCopyOption.REPLACE_EXISTING);
    return "Uploaded: " + path;
}
```

**Download**
```java
@GetMapping("/download/{filename}")
public ResponseEntity<Resource> download(@PathVariable String filename) throws IOException {
    Path path = Paths.get("uploads/" + filename);
    Resource resource = new UrlResource(path.toUri());
    return ResponseEntity.ok()
            .contentType(MediaType.APPLICATION_OCTET_STREAM)
            .header(HttpHeaders.CONTENT_DISPOSITION, "attachment; filename=" + filename)
            .body(resource);
}
```
## 7. Rate Limiting (Einschränkung von Anfragen)

📄 Einfache Variante (Resilience4j + Spring Boot Starter):
```xml
<dependency>
    <groupId>io.github.resilience4j</groupId>
    <artifactId>resilience4j-spring-boot3</artifactId>
</dependency>
```

📄 Konfiguration:
```yaml
resilience4j.ratelimiter:
  instances:
    apiLimiter:
      limitForPeriod: 5
      limitRefreshPeriod: 10s
      timeoutDuration: 0
```

📄 Verwendung:
```java
@RestController
@RequiredArgsConstructor
public class DemoController {
    @RateLimiter(name = "apiLimiter")
    @GetMapping("/limited")
    public String limited() {
        return "OK";
    }
}
```

## 9. CORS (Cross-Origin Resource Sharing)

```java
@Configuration
public class CorsConfig {
    @Bean
    public WebMvcConfigurer corsConfigurer() {
        return new WebMvcConfigurer() {
            @Override
            public void addCorsMappings(CorsRegistry registry) {
                registry.addMapping("/api/**")
                        .allowedOrigins("http://localhost:3000")
                        .allowedMethods("GET","POST","PUT","DELETE");
            }
        };
    }
}
```
## 10. Best Practices

- ✅ Verwende **DTO + @Valid** statt die Entity direkt zu verwenden.
- ✅ Behandle Fehler über **@RestControllerAdvice**.
- ✅ Füge bei GET-Anfragen immer Paginierung/Sortierung hinzu.
- ✅ Für APIs besser **ProblemDetail (RFC 7807)** verwenden.
- ✅ Dokumentiere die API über **Swagger/OpenAPI**.
- ✅ Füge zum Schutz **Rate Limiting** hinzu.
